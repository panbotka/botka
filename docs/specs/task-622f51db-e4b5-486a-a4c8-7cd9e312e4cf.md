# Compact attachments in chat

Attachments under chat messages are rendered by `AttachmentPreviews` in `frontend/src/components/MessageBubble.tsx` as large always-visible cards: images up to 300×200, PDF/text as full-width cards with Open/Download buttons, in a `flex-wrap` grid. On a phone (the primary device — iOS PWA) the bubble is 85% wide, so every card takes a whole row and a reply with several files becomes a wall of cards. JSON/HTML files also show a PDF icon.

## Requirements

### Layout
- Images: small square thumbnails (~72px, `object-cover`, rounded) in a single horizontal row that scrolls sideways when it overflows (no wrapping, hidden scrollbar, scroll snap). Tapping opens the existing `Lightbox` with swipe/arrow navigation between the message's images.
- Non-image files: compact chips (one line, ~32px tall): file-type icon + filename (middle-truncated so the extension stays visible) + size in muted text. Tapping a chip opens the file (PDF/HTML/text in a new tab, others download). A small download icon on the chip triggers download explicitly.
- Correct icons per type: image, PDF, HTML/code, CSV/spreadsheet, JSON/code, text, generic.
- Thumbnails first, then chips.

### Collapsing
- If a message has more than 4 attachments in total, render a single collapsed row "📎 N souborů" (with the first 3 image thumbnails as tiny 24px previews if any). Tap expands to the full strip; tap again collapses. State is per message, not persisted.
- 1–4 attachments render expanded.

### Both message types
- Apply to both user uploads and assistant attachments; keep their existing bubble colors.
- Works in light and dark theme. Tap targets ≥ 44px tall for chips (use padding around the 32px visual).
