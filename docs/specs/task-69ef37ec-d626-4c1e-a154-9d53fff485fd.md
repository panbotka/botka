# Show git diff on completed task detail page

Display the git changes a task produced directly in the task detail UI.

## Requirements

- Backend endpoint `GET /api/v1/tasks/:id/diff` returns the unified diff between the task's base commit and the final commit on the task branch.
- The runner records `base_commit_sha` and `head_commit_sha` columns on `tasks` at start and end of execution. Skip diff endpoint for tasks without both SHAs (return 404 with explanation).
- Endpoint response includes per-file metadata (path, additions, deletions, status: added/modified/deleted/renamed) plus the raw unified diff.
- Frontend task detail page gains a "Changes" section: file tree on the left with +/- counts, selected file's diff on the right with syntax-highlighted unified view (red/green lines).
- Large diffs (>5000 lines) collapse by default with "Show full diff" button.
- Section is hidden for tasks that never produced commits (chat-style tasks, failed tasks before any commit).

## Implementation Notes

- Use `git diff <base>..<head>` and `git diff --numstat` from the project working directory; do not parse with regex — shell out and parse `--name-status` + `--numstat`.
- For syntax highlighting reuse an existing frontend lib (e.g. `react-diff-viewer-continued` or `diff2html`).
