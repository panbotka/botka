# Project dashboard with task metrics

Add a metrics dashboard to each project page summarizing task activity and health.

## Requirements

- New section on the project detail page (or new tab) showing:
  - Total tasks (all-time) and counts by status.
  - Success rate over the last 30 days (% of completed vs failed, excluding cancelled).
  - Average task duration (running → done) over last 30 days.
  - Tasks per day for last 30 days as a small bar chart.
  - Top 5 failure reasons (grouped by `failure_summary` first sentence, or by error message if summaries unavailable).
  - Last 10 task durations as a sparkline to spot regressions.
- Backend endpoint `GET /api/v1/projects/:id/metrics` returns the aggregated data; query is cached in-memory for 60 seconds per project to avoid heavy repeated computation.
- All time-series respect the user's timezone (UTC stored, converted client-side).
- Empty state: projects with <5 tasks show "Not enough data yet" placeholder instead of charts.

## Implementation Notes

- Use a lightweight chart lib already compatible with the frontend stack (e.g. `recharts` or hand-rolled SVG for sparklines).
- Aggregations should be a single SQL query per metric; avoid N+1.
