# Hide task tags from the UI

Task tags are not used in practice and clutter the task list and detail. Remove them from the frontend only. The backend, DB tables, REST endpoints and MCP tool parameters stay untouched, so the feature can be brought back later.

## Requirements

- Task list rows no longer render tag chips next to the title.
- The tag filter bar below the status tabs on the Tasks page is gone, and the page no longer reads or writes the `?tag=` URL parameter. An old URL that still contains `?tag=` must simply be ignored (no filtering, no error).
- The Task detail page no longer shows the tag picker.
- The bulk actions bar no longer offers "Add tags" / "Remove tags" (and their modal).
- Delete frontend code that becomes unused (e.g. `TaskTagChip`, `TaskTagPicker`, `TaskTagFilterBar`, the tags modal, tag API client methods and hook parameters that nothing calls anymore). Keep the `tags` field on the TypeScript `Task` type if the API still returns it — just don't render it.
- Do NOT touch thread/chat tags (`TagHandler`, `ThreadSidebar`, `searchQuery.ts`) — that is a separate feature that stays.
- Do NOT change Go code, migrations or MCP tools.

## Implementation Notes

Touchpoints: `frontend/src/components/TaskList.tsx`, `TaskTagChip.tsx`, `TaskTagPicker.tsx`, `TaskTagFilterBar.tsx`, `BulkActionsBar.tsx`, `frontend/src/pages/TasksPage.tsx`, `TaskDetailPage.tsx`, `frontend/src/api/client.ts`, `frontend/src/hooks/useTasks.ts`, and their tests (update the TaskDetailPage tests that reference tags).

`make check` must pass (includes frontend type-check and Vitest).
