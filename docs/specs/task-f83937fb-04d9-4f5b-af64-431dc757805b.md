# Visible separator between pinned and recent threads in sidebar

Make the visual boundary between pinned and non-pinned conversations in the thread sidebar clearly visible.

## Requirements

- Replace the current subtle `border-t border-zinc-100` divider in `frontend/src/components/ThreadSidebar.tsx` (around the threadListView block) with a more visible section header for the non-pinned group.
- When at least one pinned and one regular thread are present, render a "Recent" label between them, styled identically to the existing "Pinned" and "Archived" labels (same uppercase, tracking, size, color).
- When no pinned threads exist, do NOT render the "Recent" label — the regular list should appear without any header (current behavior).
- Apply the same change to both desktop and mobile thread list views (single source of truth — the `threadListView` JSX is shared, verify it applies in both modes).
- Update existing ThreadSidebar tests to assert the "Recent" label appears only when both groups are non-empty, and add a test case for pinned-only and regular-only scenarios.

## Implementation Notes

- The separator currently lives at the line that renders `<div className="my-1.5 mx-3 border-t border-zinc-100" />` between `pinnedThreads.map(...)` and `regularThreads.map(...)`.
- Match the exact class names used by the "Pinned" header for visual consistency.
