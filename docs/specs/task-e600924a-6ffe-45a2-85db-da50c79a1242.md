# Simplified navigation

The user really uses only Chat, Tasks, Box and Dashboard (runner control). Stats, Schedules, Cron, Settings and Help are used rarely. Today the mobile bottom nav crams 9 tabs with 10px labels (`frontend/src/components/BottomNav.tsx`) and the desktop sidebar lists all items equally (`frontend/src/App.tsx`).

## Requirements

### Mobile bottom nav
- Exactly 5 slots: Chat, Tasky, Box, Dashboard, Více. Larger icons and readable labels (at least 11–12px), tap targets at least 44px.
- "Více" opens a bottom sheet (slides up, backdrop closes it, also closes on navigation) listing Stats, Schedules, Cron, Settings, Help with icons.
- When the current route is one of the secondary pages, the "Více" slot shows as active.
- Role rules stay the same: items that are admin-only today remain admin-only. For a non-admin user show only what they are allowed to see (Chat, and Help inside Více); don't render empty slots.
- Keep the bottom nav as an in-flow flex child (not `position: fixed`) with `env(safe-area-inset-bottom)` padding, and keep it hidden inside an open chat thread on mobile as today — see the "Bottom nav" and "Mobile app-shell height" notes in CLAUDE.md.

### Desktop sidebar
- Primary group on top: Chat, Tasks, Box, Dashboard (in this order).
- Then a divider and a secondary group with a small muted "Ostatní" label: Stats, Schedules, Cron, Settings, Help.
- Collapsed sidebar keeps working (icons only, divider still visible).

### Shared
- Define the nav items (path, label, icon, role, primary/secondary) in one place used by both BottomNav and the sidebar, so they can't drift apart.
