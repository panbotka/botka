# Remove auto-clickable numbered-list options from chat

Stop turning every numbered list in an assistant message into clickable
options that send the item's text to the chat on click.

## Background

`SelectableOptions.tsx` wraps ordered lists rendered from assistant markdown
(via `MarkdownContent`) and makes each list item a clickable / keyboard-selectable
control. Clicking an item (or pressing 1-9 / Enter) sends that item's text as a
new chat message through `onOptionSelect` -> `handleSend`. This fires on ANY
numbered list, including plain enumerations, which is unwanted.

## Requirements

- Ordered lists in assistant messages must render as plain, non-interactive
  markdown `<ol>` — no per-item click handler, no 1-9 / Enter selection, no
  send-on-click behavior.
- Remove the `onOptionSelect` prop threaded through `ChatView` -> `MessageBubble`
  -> `MarkdownContent`, and delete `SelectableOptions.tsx` and its usage.
- The `AskUserQuestion` / `AskUserPanel` flow must remain fully untouched and
  keep working (structured question panel is intentionally kept).
- Remove or update any tests referencing `SelectableOptions` or the
  `onOptionSelect` prop.
- `make check` must pass.
