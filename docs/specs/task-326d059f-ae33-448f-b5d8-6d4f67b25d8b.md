# Wrap long lines in chat messages and MD output

Chat bubbles and task output overflow horizontally on long URLs, file paths, and code lines, forcing horizontal scroll. Content must always fit the viewport.

## Requirements

- Default `CodeBlock` (`frontend/src/components/CodeBlock.tsx`) to `wrapLongLines={true}` so code fences wrap by default; keep the toggle to disable wrapping.
- Make the wrap toggle always visible on touch/small viewports (remove `md:opacity-0 md:group-hover:opacity-100` on mobile).
- Add `overflow-wrap: anywhere` to `.markdown-content` (and its descendants that render user text: `p`, `li`, `td`, inline `code`) in `frontend/src/index.css` so long URLs/paths wrap.
- In `TaskOutputView.tsx` text group wrapper, ensure the markdown container has the same wrapping guarantee (no horizontal overflow from long tokens).
- In `ToolCallPanel.tsx`, `pre` blocks for Input/Output already use `break-all` — verify they do not overflow their parent.
- Verify no regression in tables (`.table-wrapper` keeps `overflow-x-auto` as fallback).
- `make check` must pass; add a Vitest case for `MarkdownContent` rendering a 300-char URL without horizontal overflow (e.g. via computed style check or snapshot of container width).

## Implementation Notes

- Prefer a single CSS rule at `.markdown-content` level over per-component Tailwind classes.
- Do not touch `ChatView.tsx` layout — the bubble container (`max-w-[75%]`) is correct; the fix is at content-wrapping level.
